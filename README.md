# Food Market Prices

A Python project that fetches food commodity prices from an API, processes the data, and stores it in PostgreSQL.

## Tech Stack

- Python
- Pandas
- Requests
- PostgreSQL
- SQLAlchemy
- Psycopg

## Setup

Install dependencies:

pip install -r requirements.txt

Create a `.env` file with your API and PostgreSQL configuration.

## Run

python main.py

The pipeline fetches the latest prices, transforms the data, and stores the results in PostgreSQL.
